# Urban Hustle

A browser-based crime strategy game where you build your criminal empire.

## 🎮 [Live Demo](https://crimegame-eight.vercel.app/)

## Features

- **Character System:** Player profiles with health, energy, money, and reputation stats
- **Business Empire:** Purchase and manage various business types for passive income  
- **Crime System:** Robbery activities with dynamic success rates based on player stats
- **Banking & Finance:** Bank accounts, loans with credit scoring, and investment options
- **Casino Games:** Blackjack, Roulette, Slots, Poker, and Baccarat with real betting
- **Prison System:** Timed sentences with activities (exercise, work, sleep) to improve stats
- **Hospital System:** Medical treatments for health recovery and detox services
- **Shop & Inventory:** Equipment system with weapons and gear that boost crime success
- **Nightlife:** Bar activities and entertainment with temporary status effects
- **Admin Panel:** Avatar and business type management for administrators

## Tech Stack

- **Frontend:** React 18 + TypeScript + Vite + Tailwind CSS
- **Backend:** Supabase (PostgreSQL + Authentication + Real-time)
- **State:** Zustand with persistence
- **Deployment:** Vercel
