# Urban Hustle

Urban Hustle is a browser-based crime and city-themed game where you manage your character in an urban environment full of opportunities and dangers. The goal is to evolve your character, gain reputation, accumulate money, and complete missions using various actions and strategies.

## Main Features

- **Player Status:** Health, energy, addiction, reputation, money, and wanted level, always visible at the top.
- **Core Actions:**
  - **Robbery:** Commit robberies to earn money and reputation.
  - **Nightlife:** Recover energy and reduce addiction at clubs and parties.
  - **Hospital:** Heal your health and detox addiction.
  - **Bank:** Store your money and protect your earnings.
  - **Business:** Manage businesses for passive income.
  - **Shop:** Buy weapons, items, and consumables to upgrade your character.
  - **Casino:** Gamble and try your luck in games of chance.
  - **Lucky Wheel:** Spin the daily wheel for exclusive prizes.
- **Shopping Cart:** Add multiple items before finalizing your purchase.
- **Daily Missions:** Simple daily objectives to engage the player and reward with bonuses.
- **Dynamic Suggestions:** The game suggests actions based on your current status (e.g., low health? Go to the hospital).
- **Bottom Menu:** Quick navigation between Home, Actions, Management, Hospital, and Profile.
- **Responsive Interface:** Fully adapted for desktop and mobile.

## Technologies Used

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS

## Getting Started

1. **Clone the repository:**
   ```sh
   git clone <YOUR_GIT_URL>
   cd <YOUR_PROJECT_NAME>
   ```
2. **Install dependencies:**
   ```sh
   npm install
   ```
3. **Start the development server:**
   ```sh
   npm run dev
   ```

## Deployment

You can deploy this project using your preferred platform (Vercel, Netlify, etc). Just make sure to build with:

```sh
npm run build
```

And serve the `dist/` folder.
